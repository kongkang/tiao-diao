## 教学设计说明

- **每步一个动作**：大字幕永远是"点哪里"；绿圈高亮 + 「点这里」标签锁定按钮，圈外轻度压暗。
- **推近镜头**：向高亮区缓慢放大（最高 1.9 倍），界面文字随之放大。
- **高对比字幕**：纯白衬板 + 纯黑大标题，副标题一行以内。
- **素材口径（v3）**：全部为 devtools automator 真实截图（v0.4.0，inject-song 注入 3 分钟歌）；处理页为真实运行中截图（57%），不再使用 mock。
- **免费路径事实**：`AD_ENABLED=false` 时选「限时免费」点确认 = 直通处理页（toast「今天没有视频，这次免费帮你转」），教程演示与此一致。

## 已知取舍

- 截图为模拟器 367×794 放大，推近后清晰可读。
- 测试账号云上有 60 分钟余额，故解锁页截图里「额度下载」显示"当前余额 57 分钟"——真实新用户此处为 0 分钟并默认选中限时免费；教程主画面已用 onPick 切到限时免费选中态。
- 付费档仅作字幕带出，不做付费操作演示（避免演示真实扣款流程）。
