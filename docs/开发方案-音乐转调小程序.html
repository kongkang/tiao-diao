一、项目概览与架构

一句话：在微信小程序内，用手机本地算力把用户选择的音乐文件升高/降低音调（时长不变），通过「看视频 / 花小钱 / 包月」三种方式变现。

架构总览

┌─────────────────────────── 用户手机（全部音频数据不出设备）───────────────────────────┐
│
│  chooseMessageFile  →  readFile  →  decodeAudioData  →  PCM（Float32/Int16）
│        ↓ 选文件            ↓ 读字节            ↓ 系统解码器
│                                                              ↓
│                                          ┌────── Worker 线程 ──────┐
│                                          │  SoundTouch.wasm.br     │
│                                          │  变调 ±12 半音（WSOLA） │
│                                          └──────────┬───────────┘
│                                                     ↓
│                                          LAME.wasm.br 编码 → MP3
│                                                     ↓
│                                          writeFile → shareFileMessage → 微信聊天
└─────────────────────────────────────────────────────────────────────────────┘

┌────────── 微信云开发 CloudBase（只有订单/余额，几 KB 数据，不含音频）──────────┐
│  云函数 login → createOrder（双签名）→ 发货推送 → 加权益 → consume（扣减）
│  云数据库：users / orders / consumptions / adGrants
└──────────────────────────────────────────────────────────────────────────────┘

关键边界：音频 PCM 一辈子不出手机；上云的只有 openid、订单号、余额数字。这一点要写进隐私指引，是产品的核心卖点。

二、技术栈与选型

层选型理由 / 约束
框架原生小程序（不用 uniapp/Taro）Worker + WASM + WeUI 扩展库在原生下最稳；界面简单，无需跨端
UI 组件WeUI（useExtendedLib.weui: true）微信官方设计团队出品，不占包体积，适老友好，开发快
音频解码wx.createWebAudioContext（2.19.0+）系统解码器，免集成解码库；getChannelData 拿 Float32 PCM
变调引擎SoundTouch（C++ → Emscripten → wasm.br）成熟，setPitchSemiTones 正好是半音单位；LGPL 注意商用合规，作者提供商业授权
MP3 编码LAME（C → Emscripten → wasm.br）输出文件小、微信里能直接播放
计算线程wx.createWorker + useExperimentalWorker不卡界面；iOS 下实验 Worker 快数倍
后端微信云开发 CloudBase（云函数 + 云数据库）免服务器、免域名备案，能直接收虚拟支付发货推送；免费额度够用
支付小程序虚拟支付（wx.requestVirtualPayment，2.19.2+）2026-04-01 起强制，普通微信支付不可用
广告激励视频 wx.createRewardedVideoAdUV ≥ 1000 开流量主；做成开关，审核期关闭

6.1 选文件与解码（services/audio.js）

// 1. 选文件（只从微信聊天，这是平台唯一入口）
const res = await wx.chooseMessageFile({
  count: 1, type: 'file',
  extension: ['mp3','m4a','aac','wav','flac'],   // ⚠️ 仅 type=file 时生效
})
const file = res.tempFiles[0]
// ⚠️ 单文件约 25MB 上限，先提示
if (file.size > 25 * 1024 * 1024) return toast('文件太大了，换一个小一点的')

// 2. 读字节 → 解码成 PCM
const ab = await wx.getFileSystemManager().readFile({ filePath: file.path })
const ctx = wx.createWebAudioContext()
const audioBuffer = await new Promise((ok, err) =>
  ctx.decodeAudioData(ab.data, ok, err))   // ⚠️ 不支持的格式会走 err，要给友好提示

// 3. 拿 PCM（Float32）
const duration = audioBuffer.duration          // ⚠️ 计费与校验都靠它，真实准确
const pcmL = audioBuffer.getChannelData(0)     // Float32Array
const pcmR = audioBuffer.numberOfChannels > 1
  ? audioBuffer.getChannelData(1) : pcmL

// 4. 时长校验
if (duration > config.MAX_DURATION_SEC)
  return toast('太长了，最多 8 分钟')
⚠️ 必须真机验证的点：getChannelData 官方文档明确返回 Float32Array，但要 M0 在 iOS + 安卓真机各跑通一次。若某端行为异常，降级方案：打包 dr_libs + mpg123 + flac 的 WASM 解码器（约 300KB），自己解 mp3/wav/flac，绕开系统 API。

6.2 编译 SoundTouch → WASM（一次性构建）

# 需要 Emscripten（brew install emscripten 或 emsdk）
# SoundTouch 源码：https://www.surina.net/soundtouch/ （LGPL，商用注意合规）

# 1. 写一个薄封装 pitch_wrap.cpp，导出 C 接口：
#   st_new / st_setPitchSemiTones / st_setSampleRate / st_setChannels
#   st_putSamples(short* in, int n) / st_receiveSamples(short* out, int max)
#   st_flush / st_numSamples / st_destroy

# 2. 编译（关键：不用 Emscripten glue，编译成独立 wasm，自己 instantiate）
emcc pitch_wrap.cpp \
  SoundTouch/source/SoundLib/*.cpp \
  -O3 --no-entry -s STANDALONE_WASM \
  -s EXPORTED_FUNCTIONS='["_malloc","_free","_st_new","_st_setPitchSemiTones","_st_setSampleRate","_st_setChannels","_st_putSamples","_st_receiveSamples","_st_flush","_st_numSamples","_st_destroy"]' \
  -o soundtouch.wasm

# 3. LAME 同理（输入 interleaved short，输出 mp3 字节流）
emcc lame_wrap.c libmp3lame/*.c -O3 --no-entry -s STANDALONE_WASM -o lame.wasm

# 4. brotli 压缩（小程序支持 .wasm.br，体积省 60~70%）
brotli soundtouch.wasm -o miniprogram/wasm/soundtouch.wasm.br
brotli lame.wasm      -o miniprogram/wasm/lame.wasm.br
体积预估：SoundTouch 约 150~250KB、LAME 约 100~150KB，brotli 后合计 < 200KB。放分包或主包均可，不构成包体压力。
建议放分包，首屏不加载 WASM，用户进入选调页时再懒加载。

6.3 Worker 调度与通信协议（services/engine.js + workers/pitch.js）

// ⚠️ Worker 的限制（必须牢记）：
//   - 只能有 1 个 Worker，重建前先 terminate()
//   - 内部没有 wx 系列 API
//   - wasm 文件必须放 workers 目录外
//   - iOS 开 useExperimentalWorker，性能提升数倍，配合 onProcessKilled 重建

// 主线程：把 Float32 转成 Int16（内存减半），传给 Worker
const int16L = f32to16(pcmL), int16R = f32to16(pcmR)
const worker = wx.createWorker('workers/pitch.js', { useExperimentalWorker: true })
worker.postMessage({
  type: 'pitch',
  semitones: 2,
  sampleRate: audioBuffer.sampleRate,
  channels: 2,
  length: pcmL.length,
  pcmL: int16L.buffer,      // ArrayBuffer
  pcmR: int16R.buffer,
})
worker.onMessage(msg => {
  if (msg.type === 'progress') setProgress(msg.percent)
  if (msg.type === 'done')     handleDone(msg)     // 拿到变调后的 Int16 PCM
  if (msg.type === 'error')    handleError(msg)
})
// workers/pitch.js（伪代码骨架）
const st = await initWasm('wasm/soundtouch.wasm.br')   // WXWebAssembly.instantiate
const lame = await initWasm('wasm/lame.wasm.br')

worker.onMessage(msg => {
  if (msg.type !== 'pitch') return
  // 1. 初始化 SoundTouch
  st.st_setSampleRate(msg.sampleRate); st.st_setChannels(msg.channels)
  st.st_setPitchSemiTones(msg.semitones)

  // 2. 分块喂入（每块 8192 采样），每处理 5% 回传一次进度
  for (let i = 0; i < msg.length; i += 8192) {
    feedBlock(msg, i)
    if (i % (8192 * 50) === 0)
      worker.postMessage({ type: 'progress', percent: ~~(i / msg.length * 90) })
  }
  st.st_flush()

  // 3. 拉取输出 → LAME 编码 → MP3 字节
  const mp3Bytes = encodeLame(outL, outR, msg.sampleRate, 160) // 160kbps
  worker.postMessage({ type: 'done', mp3: mp3Bytes.buffer, length: outLen })
})

7.1 计费引擎（services/billing.js）—— 定稿规则

// ✅ 已按用户确认的四舍五入口径实现
function calcBilling(durationSec) {
  const minutes = Math.max(1, Math.round(durationSec / 60))  // 四舍五入，最少 1 分钟
  return {
    minutes,                                       // 计费分钟（3:30 → 4，6:30 → 7）
    adCount: Math.ceil(minutes / config.AD_MINUTES_PER_UNIT), // 每 3 分钟 1 个广告
    priceFen: minutes * config.PRICE_PER_MIN_FEN,  // 0.1 元/分钟
    priceYuan: (minutes * config.PRICE_PER_MIN_FEN / 100).toFixed(1),
    showMonthlyHint: minutes > 3,                  // ≥ 2 个广告时显示包月横幅
  }
}
// 边界：3:30→4分钟→2个广告/¥0.4  6:30→7分钟→3个/¥0.7

7.2 广告状态机（services/ad.js）—— 失败自动放行

async function unlockByAd(needCount) {
  if (!config.AD_ENABLED) return { ok: true, free: true }        // 开关关闭 = 全免费
  const ad = wx.createRewardedVideoAd &&
            wx.createRewardedVideoAd({ adUnitId: config.AD_UNIT_ID })
  if (!ad) return grantFree('no_ad_instance')                        // ① 能力不可用 → 放行

  for (let i = 1; i <= needCount; i++) {
    const finished = await new Promise(resolve => {
      const timer = setTimeout(() => resolve('timeout'), 8000)        // ⑤ 超时
      ad.onClose(res => { clearTimeout(timer);
        resolve(res && res.isEnded === true ? 'done' : 'skipped') })   // ③ 没看完
      ad.onError(() => { clearTimeout(timer); resolve('error') })       // ② 加载失败
      ad.show().catch(() => { clearTimeout(timer); resolve('error') })
    })
    if (finished === 'done') continue                                // 看完，进入下一个
    if (finished === 'skipped') return { ok: false, reason: 'skipped' } // 不放行，提示重看
    // error / timeout：
    if (i > 1) return grantFree('partial_done')                        // ④ 已看有效，剩余放行
    return grantFree(finished)                                          // 首条失败直接放行
  }
  return { ok: true, free: false }
}

// 风控：广告失败放行每日上限，防断网刷
async function grantFree(reason) {
  const count = await cloud.call('adGrants/today')
  if (count >= config.AD_FAIL_GRANT_MAX_PER_DAY)
    return { ok: false, reason: 'daily_limit' }
  await cloud.call('adGrants/inc')
  return { ok: true, free: true, reason }
}

async function buyProduct(product) {

7.4 权益与扣减（云函数 getEntitlement / consume）

// ===== 权益优先级：包月 > 分钟额度 =====
async function getEntitlement(openid) {
  const u = await db.users.doc(openid).get()
  return {
    monthly: u.monthlyExpireAt > Date.now(),
    monthlyDaysLeft: Math.ceil((u.monthlyExpireAt - Date.now()) / 86400000),
    minutes: u.minutes,
  }
}

// ===== 扣减（⚠️ 必须在处理成功后调用；用事务防并发）=====
async function consume(openid, minutes) {
  const ent = await getEntitlement(openid)
  if (ent.monthly) return { ok: true, deducted: 0 }      // 包月不扣额度
  if (ent.minutes < minutes) return { ok: false }
  // 同歌重转免费窗口
  if (await isRetryFree(openid, songHash, config.RETRY_FREE_MINUTES))
    return { ok: true, deducted: 0 }
  // 事务扣减 + 写流水
}

8.2 大字适配（关怀模式）

// app.js onLaunch
const { fontSizeScaleFactor } = wx.getAppBaseInfo()   // ⚠️ 不用 wx.getSystemInfo（不再维护）
// 标准 = 1，关怀模式 ≈ 1.4，最大档 ≈ 1.55
this.globalData.fontScale = Math.max(1, fontSizeScaleFactor || 1)

// 页面根节点：用动态字号 + rem 布局（不要用固定 rpx 字号）
// app.wxss 定义 :root { --fs: 16px }，页面 style 覆盖
<view style="font-size: {{16 * fontScale}}px">...</view>
// 组件内统一用 em/rem 相对单位，随根字号自动放大
实测参考：iOS 关怀模式 scaleFactor ≈ 1.4；Android 最大档 ≈ 1.55。我们把根字号 = 16px × scale，按钮高度、行高全部用 em，自动跟随。
注意：手机系统自带"字体放大"（非微信关怀模式）小程序感知不到，只能靠微信的 fontSizeScaleFactor，两者都覆盖即可。

十、开发者注意事项清单（逐条核对）

  • 广告开关：审核期 AD_ENABLED = false。微信会扫描 createRewardedVideoAd 调用，开着会被拒。
  • 苹果支付开关：MP 后台虚拟支付里单独打开"苹果支付"，否则 iOS 下单直接失败（最容易漏的一步）。
  • 道具价格必须与后台完全一致（productId + goodsPrice，单位是分），不一致报 -15013。
  • 金额绝不能由前端传给后端，只传 productId，后端查表。
  • 发货必须幂等：按 wx_order_id 去重，推送会重复。
  • 前端支付 success 只算弱确认，真正发货以后端回调 + 轮询 getEntitlement 为准。
  • Worker 只能有 1 个，重建前 terminate；内部无 wx API；wasm 放 workers 目录外。
  • WXWebAssembly 只支持包内路径（.wasm / .wasm.br），不能网络加载、不能动态编译。
  • chooseMessageFile 单文件约 25MB，flac 大文件要提示；只能选聊天记录，不能读本地文件夹。
  • shareFileMessage 必须由用户手势触发，不能自动调用。
  • 处理成功后再扣额度，失败不扣。
  • 个人主体月限额 10 万，接近上限前升级主体。
  • 沙箱与现网：env 个人主体固定 0；iOS 苹果支付没有沙箱，要用小额真实订单测。
  • ¥9.9 价格档位：建道具时实测，不合法退 ¥9.5，再不行 ¥10。
  • 真机优先：开发者工具的音频/Worker/WASM 行为与真机有差异，一切性能结论以真机为准。

  • 类目：「工具 → 图片/音频/视频处理」，避开"音乐"类目（需网络文化经营许可证）。
