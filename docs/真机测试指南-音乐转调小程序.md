# 真机测试指南 —— 音乐转调小程序（M0 内测版）

> 当前版本目标：**在手机上跑通"选歌 → 变调 → 试听 → 转调 → 发回微信"完整链路**。
> 内测版广告和支付开关全部关闭（全程免费），不需要后端、不需要云开发，导入即可跑。

## 二、导入项目（2 分钟）

1. 打开微信开发者工具 → 左侧「小程序」→「+ 导入项目」
2. 目录选择本仓库根目录：`/Users/kongkang/Developer/tiao-diao`
   （注意选**根目录**，不是 miniprogram 子目录——工具会自动按 `project.config.json` 找到代码）
3. AppID：
   - **还没注册完**：保持 `touristappid`（游客模式）也能预览，但部分能力受限
   - **注册完了**：点「导入」时填入你的真实 AppID（在 MP 后台「开发管理 → 开发设置」里能看到）
4. 项目名称随意，点「导入」

导入后如果编译器报红，先看「详情 → 本地设置」里这几项是否勾上：
- ✅ ES6 转 ES5
- ✅ 增强编译（如有）
- ✅ 将 JS 编译成 ES5（postcss）
- 不校验合法域名（已默认关）

## 三、手机上跑起来（1 分钟）

1. 手机登录的微信账号 = 开发者工具登录的微信账号（或已在 MP 后台加为体验成员）
2. 开发者工具顶部点「**预览**」→ 生成二维码 → 手机微信扫码
3. 等待编译上传（首次约 10~30 秒），手机自动打开小程序

> 如果扫码后白屏/报错，把开发者工具「调试器 → Console」里的第一条红色报错发给我。

---

## 四、测试前：先把测试歌发给自己

小程序**读不到手机里的音乐文件夹**（微信的硬限制），只能从微信聊天记录选文件。所以先准备素材：

1. 电脑微信 → 「文件传输助手」→ 拖入 3 首测试歌：
   - 一首 **mp3**（3 分钟左右，最常见的场景）
   - 一首 **m4a** 或 **wav**（验证多格式）
   - 一首 **超过 6 分钟**的长音频（验证时长上限与性能）
2. 手机微信打开「文件传输助手」，确认能看到这 3 个文件

## 五、端到端测试清单（M0 七项验证）

按顺序测，每项后面打勾。**第 1~5 项是功能正确性，第 6 项是性能，第 7 项是稳定性。**

### ☐ 1. 选文件
- 首页点「从微信聊天选音乐」→ 能跳转到聊天选择 → 选到文件传输助手 → 选中 mp3
- 选一个 **wma 文件**（京剧伴奏网站下载的很多是这个格式）→ 应明确提示"这首歌是 wma 格式……转成 mp3 再发到微信里就能转了"，而不是泛泛的"格式打不开"，更不能闪退
- 选一个**超过 25MB** 的文件，应提示文件太大

### ☐ 2. 变调与试听（核心功能）
- 进入变调页后点「+ 调高一点」→ 点「试听 15 秒」→ 声音应该**变尖但速度不变**
- 点「- 调低一点」→ 试听 → 声音变低沉、速度不变
- 「恢复原样」试听 → 和原曲一致
- 快捷档「低很多 / 低一点 / 高一点 / 高很多」都试一遍
- 连续快速点 + / - 按钮多次再试听，不应卡死

### ☐ 3. 完整转调
- 选好调后点「下一步」→「开始转调」→ 处理页有百分比进度
- 3 分钟的歌预计 **20~60 秒**完成（纯 JS 引擎，M1 换 WASM 后会快 3~5 倍）
- 完成后进入结果页，点播放键能正常播放变调后的整首歌

### ☐ 4. 发回微信保存
- 结果页点「发回微信聊天」→ 跳到聊天选择 → 发给自己（文件传输助手）
- 在聊天里点开收到的 .wav 文件，能播放
- 长按文件能「保存到手机」（iOS 存到"文件"App；安卓存到本地）

### ☐ 5. 大字版兼容
- 微信「我 → 设置 → 关怀模式」开启 → 重新进小程序
- 所有文字应该明显变大，按钮不重叠、文字不截断（重点看首页三步引导和变调页快捷档）

### ☐ 6. 性能实测（记录数据发我）
- 处理 3 分钟歌：从点击"开始转调"到完成，约____秒
- 处理 6 分钟歌：约____秒，中途是否闪退/卡死
- 手机发热情况：□ 无感 □ 微热 □ 烫手
- 处理过程中切到后台再切回来，是否正常继续或给出提示

### ☐ 7. 稳定性（使劲折腾）
- 处理中按左上角返回 → 应弹提示或直接退出，**再进不能闪退**
- 连续转 3 首歌（中间不退出小程序），第 3 首仍正常
- 处理中锁屏 30 秒再解锁，看是否继续
- 结果页点「换个调重转」→ 回到变调页 → 再转一次，不重复提示扣费

## 六、发现问题怎么办

把这三样发我：
1. **现象**：哪一步、什么表现（截图/录屏最好）
2. **报错**：开发者工具「调试器 → Console」红色报错文字（真机测试时可在小程序里打开调试：预览二维码时勾"自动打开调试"，手机上点右下角悬浮 vConsole 按钮）
3. **手机型号 + 系统版本**（如 iPhone 13 / iOS 17.2）

## 七、当前版本的已知边界（不是 bug）

| 现象 | 原因 | 解决阶段 |
|---|---|---|
| 输出是 .wav 不是 .mp3（文件较大，3 分钟歌约 30MB） | M0 故意用 WAV 绕开编码瓶颈，保证先能跑通 | M1 换 WASM 编码后改 mp3，文件小 8 倍 |
| 处理速度一般（3 分钟歌 20~60 秒） | 纯 JS 引擎 | M1 换 WASM 引擎提速 3~5 倍 |
| 全程免费、无广告、无付费入口 | 开关全关，等审核通过+开通流量主/虚拟支付后再开 | M2 |
| 「买分钟」页提示"内测期间免费使用" | 同上 | M2 |
| 不支持选手机本地音乐文件、不能直接存相册 | 微信平台硬限制，所有小程序都一样 | 永久限制，UI 已用引导规避 |
