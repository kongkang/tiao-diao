# 交接 —— 贴链接导入(B站/唱吧/全民K歌)+ 付费下载复用

2026-11-23 · 分支 feat/link-import(基线=主工作区未提交改动快照,与本地完全一致)

## 一句话

首页多了「贴链接导入」:粘贴 B站/唱吧/全民K歌 的分享文案 → 云端解析并提取音频 → 进**现有**的试听→选调→解锁(看广告/余额/包月)→转调→发回微信管线。**计费口径一个字没改**:免费=解析+3分钟试听;下载/导出按分钟收费,导入的歌结果页多一个「发原曲」(本次已付费,不另扣)。

## 部署状态(2026-11-24 更新)

- ✅ `parseMedia` 已部署(2026-11-24,代码为最新)
- 🔄 `fetchMedia` 已改为**分块断点续传协议**(2026-11-24 feat/link-import-chunked):每次调用限时 ~2.6s/1.5MB,端上循环拉取拼接,**函数默认 3 秒超时即可运行**;提取有真实百分比进度

## 真机验证清单(按顺序,约 15 分钟)

**B站主路径(已本地实测,优先验这个)**
1. B站 App 随便找个 MV → 分享 → 复制链接 → 小程序首页「贴链接导入」→ 点「粘贴」→ 应自动解析出标题/封面/时长。
2. 点「提取音频,去试听」→ loading 显示「正在提取音频 N%」→ 几秒到十几秒后进选调页 → ▶ 试听正常。
3. 解锁页走一遍(免费态/广告演示/余额,任一)→ 转调 → 结果页应多「发原曲到微信」按钮 → 点它能发出原音频。
4. 转调后的文件照常「发回微信」。

**计费口径(重点确认)**
5. 导入的歌在解锁页显示的分钟数 = 按**歌曲时长**算(和本地选歌一致),不是按视频清晰度。
6. 内测免费态全流程不弹付费;PAY_OFFLINE_FREE=false 时断云会提示。

**边界用例**
7. 抖音链接粘贴 → 应弹「抖音的解析要专门的签名服务…」(人话,不是裸报错)。
8. 胡乱文字 → 「没认出链接…」。
9. 唱吧/全民K歌分享链接 → **接口是尽力而为,没实测过**,失败会给人话提示;不通不阻塞 B站主路径。
10. 长视频(>20 分钟)提取可能撞云函数 55s 超时 → 提示「先试 5 分钟以内的」,属预期。

## 视频号上线配置(可选,不配则该平台给人话提示,其他平台不受影响)

视频号没有公开解析 API,当前唯一可行的服务端路径是**借腾讯元宝的授权**(参考 ltaoo/wx_channels_download 与 ga-ven/douyin-wx-video-download 的实现):

1. 用你自己的账号登录 [yuanbao.tencent.com](https://yuanbao.tencent.com)(微信扫码即可)
2. 浏览器 F12 → Network(或 Application→Cookies)→ 复制**完整 Cookie 字符串**
3. 云开发控制台 → 云函数 → `fetchMedia` → 函数配置 → 环境变量 → 新增:
   - key: `YUANBAO_COOKIE`
   - value: <粘贴整段 Cookie>
4. 保存后函数自动生效(不用重新部署代码)

⚠️ 风险与维护须知:元宝接口**非官方公开 API**,Cookie 会过期(过期后用户侧收到「Cookie 失效,去控制台更新」的人话提示,重复上面步骤即可);自动化访问有账号风控风险,请用自己可接受的账号评估。

## 已知限制与风险

- **唱吧/全民K歌**:解析靠播放页正则,接口随时会变;全民K歌的 playurl 若是加密串则解析失败——需要时抓包补解密。
- **分块提取**:函数超时 3 秒默认档下,5 分钟歌曲约 4~8 次云调用(实测本地 1 秒拉完 5.4MB;云上含冷启动约 10~25 秒)。冷启动偶发云调用失败,客户端已做断点自动重试(同 offset 续传,进度不丢)。抖音 2.4MB 作品实测 2 次调用拉完。
- **合规**:审核版建议 `LINK_IMPORT_ENABLED=false`;对外文案已定位为「链接导入」而非「视频下载」。仅处理用户有权使用的内容。
- **伴奏生成**:本版不含。需要 GPU 级源分离(Demucs 等),云开发 60s 跑不动,须自建/托管 GPU 服务,接口位已留在 fetchMedia 之后。

## 回滚

config.js `LINK_IMPORT_ENABLED=false` → 入口消失、页面显示整修提示,云函数留着不碍事。
