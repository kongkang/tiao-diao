# 交接 —— 贴链接导入(B站/唱吧/全民K歌)+ 付费下载复用

2026-11-23 · 分支 feat/link-import(基线=主工作区未提交改动快照,与本地完全一致)

## 一句话

首页多了「贴链接导入」:粘贴 B站/唱吧/全民K歌 的分享文案 → 云端解析并提取音频 → 进**现有**的试听→选调→解锁(看广告/余额/包月)→转调→发回微信管线。**计费口径一个字没改**:免费=解析+3分钟试听;下载/导出按分钟收费,导入的歌结果页多一个「发原曲」(本次已付费,不另扣)。

## 真机验证清单(按顺序,约 15 分钟)

**B站主路径(已本地实测,优先验这个)**
1. B站 App 随便找个 MV → 分享 → 复制链接 → 小程序首页「贴链接导入」→ 点「粘贴」→ 应自动解析出标题/封面/时长。
2. 点「提取音频,去试听」→ loading 显示「正在提取音频 N%」→ 几秒到十几秒后进选调页 → ▶ 试听正常。
3. 解锁页走一遍(免费态/广告演示/余额,任一)→ 转调 → 结果页应多「发原曲到微信」按钮 → 点它能发出原音频。
4. 转调后的文件照常「发回微信」。

**计费口径(重点确认)**
5. 导入的歌在解锁页显示的分钟数 = 按**歌曲时长**算(和本地选歌一致),不是按视频清晰度。
6. 内测免费态全流程不弹付费;PAY_OFFLINE_FREE=false 时断云会提示。

**边界用例**
7. 抖音链接粘贴 → 应弹「抖音的解析要专门的签名服务…」(人话,不是裸报错)。
8. 胡乱文字 → 「没认出链接…」。
9. 唱吧/全民K歌分享链接 → **接口是尽力而为,没实测过**,失败会给人话提示;不通不阻塞 B站主路径。
10. 长视频(>20 分钟)提取可能撞云函数 55s 超时 → 提示「先试 5 分钟以内的」,属预期。

## 视频号:双路解析与 Cookie 有效期实测(2026-11-24)

**免配置即用**:视频号主路走 mtotech 公共解析(`POST https://v.mtotech.com/api/resolve`,文档化公开接口,无需密钥,对方维护会话)。实测 1.17MB 作品成功提取。代价:该接口延迟波动 1.7~5s,在函数 3s 默认超时下**部分调用会被平台掐断**,客户端已做断点自动重试(同 offset,进度不丢),整体成功率靠重试堆出来。

**两条增强(都可选)**:
1. **提高超时墙**:云开发控制台 → fetchMedia → 函数配置 → 超时调到 **10 秒**,同时加环境变量 `FETCH_WALL_MS=9000` → 视频号解析不再被掐,一次调用完成(其他平台分块也会变大、更快)。
2. **自持 Cookie(元宝路)**:登录 [yuanbao.tencent.com](https://yuanbao.tencent.com) → F12 复制完整 Cookie → 控制台给 fetchMedia 加环境变量 `YUANBAO_COOKIE`。配置后视频号**优先走元宝授权链路**(云上到腾讯内网,亚秒级,3s 超时下也稳),mtotech 自动降为备用。⚠️ 元宝接口非官方 API,Cookie 会过期、有账号风控风险。

**Cookie 有效期实测(谁来测)**:
- 已内置探针:`node tools/yuanbao-cookie-probe.js`——读 `tools/yuanbao-cookie.txt`(已 gitignore,把复制的 Cookie 原样放进去即可),POST 元宝接口判定 2xx=有效 / 401=失效,结果追加到 `tools/yuanbao-cookie-probe.log`(带"放入文件起第几天")。
- 已挂**每日定时探针**(自动跑),日志会积累出真实的过期天数;哪天翻成 INVALID 就是确切寿命。
- 社区现状(ltaoo/wx_channels_download issue #508 等):**服务端解析视频号,元宝 Cookie 就是当前通用做法**,没有公开的免凭据方案;唯一免 Cookie 的路线是桌面端嗅探/注入(res-downloader、wx_channels_download),不适用小程序后端。知乎有案例提醒:同 Cookie 历史链接能解、新链接失败 ≠ Cookie 过期,可能是作者限制了站外解析。

## 已知限制与风险

- **唱吧/全民K歌**:解析靠播放页正则,接口随时会变;全民K歌的 playurl 若是加密串则解析失败——需要时抓包补解密。
- **分块提取**:函数超时 3 秒默认档下,5 分钟歌曲约 4~8 次云调用(实测本地 1 秒拉完 5.4MB;云上含冷启动约 10~25 秒)。冷启动偶发云调用失败,客户端已做断点自动重试(同 offset 续传,进度不丢)。抖音 2.4MB 作品实测 2 次调用拉完。
- **合规**:审核版建议 `LINK_IMPORT_ENABLED=false`;对外文案已定位为「链接导入」而非「视频下载」。仅处理用户有权使用的内容。
- **伴奏生成**:本版不含。需要 GPU 级源分离(Demucs 等),云开发 60s 跑不动,须自建/托管 GPU 服务,接口位已留在 fetchMedia 之后。

## 回滚

config.js `LINK_IMPORT_ENABLED=false` → 入口消失、页面显示整修提示,云函数留着不碍事。
