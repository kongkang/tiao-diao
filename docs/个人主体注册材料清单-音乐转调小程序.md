> 整理日期：2026-10-05
> 依据：微信公众平台官方注册流程 + 小程序备案操作指引（微信开放文档）

## 一、先看清楚：个人主体能做什么、不能做什么

### 能做
- 用本人身份证注册，**免 300 元/年微信认证费**，注册最快
- 类目选「工具」下的 **「图片处理」**（见下方说明，这个类目正好覆盖你的场景）
- 接激励视频广告变现（需累计 UV ≥ 1000）
- **可开通虚拟支付**（个人主体已开放，见第四节）

### 不能做（个人主体红线，别碰）
| 类目/能力 | 原因 |
|---|---|
| 线上商城、餐饮外卖、线下收银 | 交易类，个人主体完全不开放 |
| 金融理财、医疗、教育培训招生 | 需专项资质 |
| 会员储值大额交易 | 交易类，不开放 |
| **音乐 / 音频版权类目** | 需《网络文化经营许可证》，**这是你最大的雷区** |

> ⚠️ **命名红线**：不要用「音乐」「歌曲」「歌单」「K歌」「电台」「FM」「有声读物」等词。
> 文案统一用「音频文件处理」「变调」「文件转换」。

## 二、注册阶段要准备的材料（自己填，我不用看）

这些是**隐私敏感信息**，你自己在微信公众平台填就行，**不需要也不应该发给我**。

| # | 材料 | 说明 |
|---|---|---|
| 1 | **全新邮箱** | 必须**从未绑定过微信公众平台**（公众号/小程序/企业微信都不行）。一个邮箱只能注册 1 个小程序 |
| 2 | **本人二代身份证** | 有效期需 > 1 个月，拍照要清晰无反光 |
| 3 | **本人实名微信 + 手机号** | 手机号要能收验证码，且**保持畅通**（备案期间会打电话核验） |
| 4 | **本人银行卡** | 开通虚拟支付时填提现账户，**提交后不可改**，第一笔会打 0.01 元验证 |
| 5 | 小程序名称 | 想好再填，**个人主体每年只能改 2 次** |
| 6 | 头像 + 功能介绍 | 介绍和头像可多次改 |

### 注册路径
浏览器打开 `mp.weixin.qq.com` → 右上角「立即注册」→ 账号类型选**小程序**（别选成公众号）→ 填邮箱 → 邮箱点激活链接 → 主体类型选**个人** → 填主体信息 → 管理员微信扫码确认

## 三、备案阶段要准备的材料（唯一长周期，今天就启动）

**耗时：平台初审 1-2 工作日 → 短信核验 → 通管局审核 1-20 工作日。整体 7~20 工作日。**

未备案**无法提交代码审核**，这是硬门槛。

### 个人主体备案材料清单

| # | 项目 | 具体要求 |
|---|---|---|
| 1 | **主体证件** | 居民身份证原件彩色扫描件/拍照件。避免反光、信息不全、遮挡；**有效期距到期 > 3 个月** |
| 2 | **主体负责人信息** | 个人主体默认复用本人信息。手机号填本人有效号码，**不同人不能用同一个号码** |
| 3 | **通讯地址** | 填**实际可联系的真实地址**，决定备案所属省份管局。⚠️ 选广东省的话，备案承诺书为必填 |
| 4 | **小程序信息** | 名称、服务内容标识、备注（**20-200 字**，描述主要功能） |
| 5 | **前置审批** | 你的项目**不涉及**，选「以上都不涉及」 |
| 6 | **负责人证件照** | 身份证正反面，清晰无遮挡 |
| 7 | **人脸核验** | 白色/浅色干净背景，不戴帽子/口罩/耳机，不露上半身，表情自然不闭眼 |
| 8 | **应急手机号** | 与负责人手机号**不能相同** |

### 备案入口
登录 `mp.weixin.qq.com` → 首页「**去备案**」按钮，或 设置 → 小程序备案

### ⚠️ 两个致命时间点
1. **工信部短信核验：收到短信后 24 小时内必须完成**，超时自动驳回，要重新提交！
   - 短信来自 **12381**，登录 `beian.miit.gov.cn` 核验
2. **每日提交有配额限制**，当日额度用完按钮还在但提交不了，次日 10:00 刷新

### 备案四要素一致性（管局会查）
> **小程序名称、服务内容、备注、主体名称** 四者必须有明显关联性，不能相悖。

举例：名称「XX 音频变调工具」+ 服务内容「图片/音频/视频本地处理」+ 备注「提供本地音频变调处理」→ 关联性成立 ✅

## 五、变现相关：两个开通条件

### 1. 激励视频广告（流量主）
- **开通门槛：累计独立访客 UV ≥ 1000，且无违规记录**
- 入口：小程序后台左侧「推广 → 流量主」
- 审核时效：功能开通即时，**财务资料审核 7 个工作日**，广告组件审核 1 个工作日
- 结算：绑个人银行卡，每月两次结算
- ⚠️ **审核期必须关闭广告**，否则驳回

> 💡 收益参考：激励视频 CPM 约 20-50 元，是个人开发者收益最高的广告形式。你的「看广告解锁转调」设计正好契合。

### 2. 虚拟支付（额度包）
个人主体**已开放**（2026 年新政策，推翻了旧规则）。

| 项 | 内容 |
|---|---|
| **开通条件** | ① 已认证的小程序 ② 主体信息完备 ③ 服务类目含「工具」④ **已完成备案** |
| **月限额** | **10 万元（全终端合计）** → 超此量级建议注册个体工商户 |
| **入口** | 小程序后台 →「支付与交易」→「虚拟支付」 |
| **审核时效** | 个人主体一般 **5 分钟内**出结果 |
| **费率** | Android/鸿蒙/Windows 主动支付 **1%**（限时优惠，标准 10%）<br>iOS **12%**（全是 Apple 佣金，腾讯 5% 技术费限时减免） |
| **开通流程** | 同意支付协议 → 提交商户资料（身份证 + 银行卡 + 支付管理员）→ 签约验证 |

**道具配置**：¥1=10分钟 / ¥3=30分钟 / ¥6=60分钟，单位「分」，发布后约 10 分钟生效。

**签名双密钥**（只能放云函数，绝不进前端）：
```
paySig    = HMAC-SHA256(AppKey, "requestVirtualPayment&" + signData)
signature = HMAC-SHA256(session_key, signData)
```
`signData` 必须前后端**一个字符都不差**。
